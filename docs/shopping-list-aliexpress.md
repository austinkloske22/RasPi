## Display Setup Guide

### Connecting HDMI Touchscreen to Pi 4

```
Pi 4 micro-HDMI Port 1  →  Touchscreen HDMI In
Pi 4 USB Port          →  Touchscreen USB (for touch input)
Pi 4 USB-C Power       →  Power supply
Touchscreen Power      →  Same power supply (if needed) or USB from Pi
```

### Software Setup

```bash
# Usually works out of the box with Raspberry Pi OS
# If needed, configure display rotation:

sudo nano /boot/config.txt

# Add these lines:
hdmi_group=2
hdmi_mode=87
hdmi_cvt=1024 600 60 6 0 0 0
display_rotate=0  # 0=normal, 1=90°, 2=180°, 3=270°

# Reboot
sudo reboot
```
