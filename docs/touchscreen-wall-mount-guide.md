## Cable Management Solutions

### Method 1: In-Wall Routing (Cleanest)

**Materials Needed:**
- Cable pass-through plate (€5-10)
- Drywall saw or drill
- Cable fish tape (€8-15)

**Process:**
1. Cut small hole behind display mounting location
2. Route power cable through wall to outlet below
3. Install cable plate for professional finish

**Result:** No visible cables at all

---

### Method 2: Surface Cable Channel (Easy)

**Materials:**
- D-Line cable raceway/channel (€8-15 for 1m)
- Available at: Gamma, Praxis, Amazon.nl, AliExpress

**Sizes:**
- 20×10mm for single power cable
- 30×15mm for multiple cables

**Colors:** White, black, wood effect, paintable

**Result:** Clean line from display to outlet

---

### Method 3: Cable Sleeve (Quick)

**Materials:**
- Neoprene cable sleeve (€5-10)
- Available: Amazon.nl, AliExpress

**Result:** Bundles cables into single black/white sleeve

## Installation Steps

### 1. Prepare Display Assembly
- Attach Pi 4 to back of touchscreen using standoffs
- Connect DSI ribbon cable (official) or HDMI+USB (clone)
- Mount in chosen case/enclosure
- Test before wall mounting!

### 2. Choose Wall Location
- Living room wall with good viewing angle from seating
- Near power outlet (or plan cable routing)
- Comfortable height: 140-160cm from floor
- Away from direct sunlight (glare on screen)

### 3. Install Cable Management
- **If in-wall:** Cut pass-through hole, route cables
- **If surface:** Install cable channel first
- Route power cable to outlet

### 4. Mount Display
- **VESA mount:** Attach bracket to wall studs or use wall anchors
- **Adhesive:** Use heavy-duty 3M Command strips (rated 7kg+)
- **Screws:** Use appropriate anchors for your wall type

### 5. Connect & Configure
- Power on Pi 4
- Configure touchscreen calibration if needed
- Set up Grafana dashboard for plant monitoring
- Enable screen sleep/dimming for living room use

## FAQ

**Q: Can I mount without drilling holes?**
A: Yes! Use heavy-duty 3M Command Picture Hanging Strips (rated 7-12kg). The Pi 4 + 7" display weighs ~400g, so 4-6 strips are plenty.

**Q: Will cables be visible?**
A: With proper cable management (in-wall routing or cable channels), cables can be completely hidden or minimal. SmartiPi Touch 2 has excellent built-in routing.

**Q: What about power outages?**
A: Pi 4 will restart automatically. Consider adding a small UPS (€25-40) if power stability is important.

**Q: Can I remove it later without damage?**
A: Yes if using Command Strips. VESA mounts leave small screw holes (easy to fill).

**Q: Touchscreen works through case?**
A: Cases are designed with cutouts or thin acrylic fronts that preserve full touch functionality.
