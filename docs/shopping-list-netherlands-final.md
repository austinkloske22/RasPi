## ESP32 Automation Architecture

### How ESP32 Controls Pumps

```python
# ESP32 Firmware (Arduino/PlatformIO)

#define RELAY_PIN 4        // GPIO4 controls relay
#define SENSOR_PIN 34      // GPIO34 reads moisture (analog)
#define PUMP_TIME 5000     // 5 seconds watering

void waterPlant() {
  digitalWrite(RELAY_PIN, LOW);   // Turn pump ON (relay active LOW)
  delay(PUMP_TIME);
  digitalWrite(RELAY_PIN, HIGH);  // Turn pump OFF

  // Publish to MQTT
  client.publish("plants/living_room_01/watered", "5s");
}

void loop() {
  int moisture = analogRead(SENSOR_PIN);

  // Auto-water if too dry
  if (moisture < THRESHOLD_DRY) {
    waterPlant();
  }

  // Or wait for MQTT command from dashboard
  // "plants/living_room_01/water" → waterPlant()

  // Sleep for 6 hours
  esp_deep_sleep_start();
}
```

### Wiring: ESP32 + Sensor + Pump + Relay

```
┌─────────────────────────────────────┐
│         ESP32 DevKit C              │
│                                     │
│  GPIO34 (ADC) ←─── Moisture Sensor │
│  GPIO4 ────────→ Relay IN          │
│  GND ──────────→ Sensor GND, Relay GND
│  3.3V ─────────→ Sensor VCC        │
│  VIN (5V USB) ─→ Relay VCC         │
└─────────────────────────────────────┘
         │                    │
         │                    │
    ┌────▼─────┐         ┌───▼────┐
    │  Sensor  │         │ Relay  │
    │ (in soil)│         │ Module │
    └──────────┘         └───┬────┘
                             │
                         ┌───▼────┐
                         │  Pump  │
                         │  5V    │
                         └────────┘
```

**Power:**
- ESP32: USB power (from 10-port charger)
- Pump: Relay switches pump power from same USB source
- All powered from one USB port (5V 2A)
